# Teacher Lesson Planner Pack — Start here

Simple **markdown templates** for lesson planning — printable or copy into Docs/Notion.

## What's included

| File | Purpose |
|------|---------|
| `templates/01-lesson-plan.md` | Single-lesson plan |
| `templates/02-week-at-a-glance.md` | 5-day week overview |
| `templates/03-supply-list.md` | Materials / prep checklist |

Also: `LICENSE` (MIT) · `listing-gumroad.md`

## Quick start

1. Duplicate `01-lesson-plan.md` per lesson or period.
2. Fill standards, objectives, and timing blocks.
3. Use week-at-a-glance on Sunday for the upcoming week.
4. Print supply list before shopping / pulling from closet.
